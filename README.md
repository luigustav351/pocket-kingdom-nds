# Pocket Kingdom
# Regras rápidas:
# - Construa casas, fazendas, serrarias, pedreiras, mercados e castelo.
# - Clique em um espaço vazio para construir.
# - Botão direito remove uma construção.
# - Use 1 a 6 para trocar o tipo de construção.
# - Alcanze prosperidade e construa o castelo para vencer.

Pocket Kingdom é um protótipo jogável de city-builder inspirado em simuladores de gestão e vida, pensado para funcionar como base para um jogo mais avançado no estilo Nintendo DS.

Objetivo:
- Gerenciar recursos.
- Aumentar a população.
- Construir infraestruturas.
- Expandir o reino.
- Conquistar a vitória com o Castelo.

Como jogar:
1. Instale o Python 3.10+.
2. Instale o Pygame:
   pip install -r requirements.txt
3. Execute:
   python main.py
4. Clique na área do mapa para construir.
5. Use o painel direito para escolher o tipo de construção.
6. Pressione 1, 2, 3, 4, 5 ou 6 para trocar rapidamente.
7. Clique com o botão direito para remover uma construção.

Recursos:
- Madeira
- Pedra
- Comida
- Ouro

Construções:
- Casa: +2 população
- Fazenda: +5 comida
- Serra: +4 madeira
- Pedreira: +4 pedra
- Mercado: +5 ouro
- Castelo: vitória

Observações:
- O protótipo foi criado para funcionar em PC e servir como base de portabilidade para um jogo NDS/DS Homebrew futuramente.
- A visualização e o sistema foram simplificados para manter o projeto executável e fácil de expandir.
